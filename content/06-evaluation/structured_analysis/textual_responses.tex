\textbf{Textual responses - Competitive variant}

\textit{Do you have any comments or suggestions for improvement regarding this course?}

There were 2 answers in total. One student stated: \enquote{It was really educational.} Apart from that, we only received suggestions for improvement in the course design - a request for more clear requirements in cardinality exercises and a comment about multiple tries mechanics in exercises.

\textit{What effect did the slightly aggressive narration in the theory sections have on you?}

Only one answer was provided: \enquote{Positive}.

\textbf{Textual responses - Playful variant}

The \ac{pv} received significantly more responses that were both more elaborate and more enthusiastic. That is indicative of higher engagement rate and a better mood in the participants after having taken the course compared to \ac{cv}.

\textit{Do you have any comments or suggestions for improvement regarding this course?}

Students made multiple suggestions for improvement, such as adding more hints after incorrect responses, improving navigation in the course, or adding a summary page for all the concepts. There was a complaint that some questions did not have fully deterministic answers.
